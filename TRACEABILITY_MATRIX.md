# Scope B Traceability Matrix (Frozen Baseline vs Implementation)

| Requirement ID | Frozen Baseline Definition | Implementation Status | Corresponding Real OS Mechanism & Architectural Guarantees | Verified by Test |
| :--- | :--- | :--- | :--- | :--- |
| **REQ-SCOPE-B-01** | Oracle isolation; refusal after zeroization | **IMPLEMENTED** | Key material generated exclusively inside worker via `os.urandom(32)` prior to seccomp activation, strict pipe protocol, complete buffer zeroization (`ZEROIZE`), and unconditional `OPERATION_REFUSED` post-zeroization. *Note: Confidentiality against the parent process relies explicitly on the OS isolation controls of B-02 and B-05 (UID separation and `PR_SET_DUMPABLE=0`).* | `test_scope_b_01_zeroization_lifecycle` |
| **REQ-SCOPE-B-02** | ptrace / dump / UID isolation | **IMPLEMENTED** | UID separation (`65534`), `PR_SET_DUMPABLE(0)` with verified `PR_GET_DUMPABLE == 0`. Verified via an independent, unprivileged same-UID (`65534`) probe process receiving `EPERM`/`EACCES` on `/proc/<pid>/mem`. | `test_scope_b_02_mem_access_denied`, `test_scope_b_kernel_state_enforcement` |
| **REQ-SCOPE-B-03** | seccomp, SECCOMP_RET_KILL_PROCESS | **IMPLEMENTED** | Strict BPF seccomp filter installed via `prctl(PR_SET_SECCOMP, SECCOMP_MODE_FILTER)` enforcing `SECCOMP_RET_KILL_PROCESS` on disallowed syscalls. | `test_seccomp_sigsys_kill` |
| **REQ-SCOPE-B-04** | Fail-Closed Mechanism on Security Breach | **IMPLEMENTED** | `PR_SET_PDEATHSIG(SIGKILL)` terminates the worker immediately upon unexpected parent termination, reclaiming key pages via OS teardown (best-effort path per INV-B-02; guaranteed explicit buffer scrubbing is provided by the `ZEROIZE` command path in B-01). | `test_worker_process_unexpected_termination` |
| **REQ-SCOPE-B-05** | Privilege Separation & UID isolation | **IMPLEMENTED** | Strict UID/GID drop to `65534`, capability bounding set zeroing (`CapEff`/`CapBnd` = 0), `PR_SET_NO_NEW_PRIVS`, and `PR_SET_DUMPABLE(0)` re-verified post-setuid. | `test_scope_b_kernel_state_enforcement` |
| **REQ-SCOPE-B-06** | Memory Locking & Hardening | **IMPLEMENTED** | Strict `mlockall(MCL_CURRENT | MCL_FUTURE)` with fail-closed startup halt on failure. | `test_scope_b_kernel_state_enforcement`, `test_mlockall_failure` |
| **REQ-SCOPE-B-07** | Dedicated watchdog process | **IMPLEMENTED** | Independent unprivileged watchdog process (`UID 65534`) monitoring worker liveness over a dedicated IPC pipe (`wd_conn`) separate from main-process traffic, driving the worker to a fail-closed state (`SIGKILL`) upon unresponsiveness. | `test_scope_b_07_watchdog_monitoring` |
