# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-08-16

### Added
* **Deterministic RAM Zeroization:** Introduced `SecureMemoryBuffer` for instant and reliable wipe of sensitive cryptographic keys and credentials.
* **Multi-Party Authorization (MPA):** Added secure recovery workflows requiring multiple administrative approvals.
* **Fail-Closed Engine:** Implemented hysteresis suppression to prevent unauthorized state mapping under duress.
* **Automated CI Pipeline:** Configured GitHub Actions for continuous integration, code validation, and test coverage across Python environments.
* **Security & Documentation:** Established clear contribution guidelines, MIT license, and direct security vulnerability reporting policies.
